# Home

Purpose:
Immediately communicate ZAN's identity and investment positioning.

Content:
- Main headline
- Supporting description
- Primary CTA
- Secondary CTA
- Strong investment/business visual

## About Preview

Short introduction to ZAN.

## Investment Areas

Present the major areas/sectors in which ZAN operates.

## Featured Projects

Show selected projects or investments.

Each item may include:

- Name
- Sector
- Location
- Status
- Short description
- Image

## Investment Opportunities

Preview selected investment opportunities.

Each item may include:

- Name
- Sector
- Location
- Status
- Short description
- CTA

## Strategic Partners

Display selected partner logos.

Encourage investors and strategic partners to start a conversation.

# Investments & Projects

Purpose:
Present ZAN's projects and investments.

Project information:

- Project name
- Sector
- Location
- Status
- ZAN's role
- Description
- Images
- Additional information where appropriate

Possible statuses:

- Active
- Under Development
- Under Execution
- Expansion
- Completed


# Investment Opportunities

Purpose:
Present current investment opportunities.

Opportunity information:

- Name
- Sector
- Description
- Status
- Opportunity type
- Location
- Key advantages
- Investment size when publishable
- CTA

The interface must allow future opportunities to be added easily.

Sensitive investment information should not be exposed unless approved.


# Services

Services should be presented as part of ZAN's investment and project ecosystem.

Avoid positioning the page as a generic agency/service-provider page.

Services may be grouped by their relationship to:

- Investment
- Project development
- Project management
- Operations
- Business support
- Strategic development

# Content Rule
