# ZAN Corporate Website

A premium multilingual corporate website for ZAN, a Saudi investment company.

## Project Overview

This project represents ZAN's official corporate digital presence.

The website focuses on presenting ZAN as an investment and project-focused company, highlighting its projects, investment opportunities, strategic partnerships, capabilities, and communication channels.

The website should communicate:

- Trust
- Stability
- Professionalism
- Authority
- Investment capability
- Growth
- Premium positioning

## Phase 1

Phase 1 is a frontend-focused corporate website.

### Languages

- Arabic
- English
- Russian

### Main Pages

- Home
- About
- Investments & Projects
- Investment Opportunities
- Services
- Strategic Partners
- Investors & Partnerships
- Contact

## Technology Direction

The preferred frontend stack is:

- React
- Vite
- Tailwind CSS
- React Router
- Lucide React
- Framer Motion when justified
